# Bilal: онлайн-заказы, бонусы, QR на столах

Сайт, где клиент сам собирает заказ. Заказ приходит на моноблок кассы со звуком, кассир подтверждает его одной кнопкой.

- **Сайт клиента** (`/`):
  - меню филиала с фото (приходит с кассы), корзина;
  - доставка или самовывоз, адрес и точка на карте;
  - оплата при получении или переводом по QR филиала, с прикреплённым чеком;
  - статус заказа в реальном времени, повтор заказа.
- **QR на столах** (`/?b=1&t=5`): заказ из зала с номером стола, оплата на кассе.
- **Бонусы:**
  - кэшбэк;
  - бонус за первый заказ;
  - «пригласи друга»;
  - «счастливые часы» (×2 бонусов);
  - сгорание бонусов без заказов;
  - оплата бонусами до N% заказа.
- **Защита:**
  - цены считает сервер;
  - бонусы можно тратить только с телефона, на который уже выдавали заказ;
  - большой заказ принимается только после звонка;
  - «не забрал» 2 раза — дальше только предоплата;
  - ограничение частоты заказов.
- **Админка владельца** (`/admin`):
  - сводка по филиалам;
  - настройки филиалов (часы, доставка, QR для перевода);
  - ключи касс;
  - печать QR на столы;
  - правила бонусов, акции, клиенты (начислить или списать бонусы).
- **Касса** (`bilal-pos`): вкладка «Онлайн-заказы» и значок с уведомлением на всех экранах. Установка описана в [`pos_addon/INSTALL.md`](pos_addon/INSTALL.md).

Нужен только стандартный Python 3.11+, внешних библиотек нет. Данные хранятся в SQLite на диске Render.

## Запуск на Render

1. render.com → **New → Blueprint** → этот репозиторий → **Connect**.
2. Render спросит `ADMIN_PASSWORD`: придумайте пароль для `/admin`.
3. Через 2–3 минуты откройте `https://АДРЕС.onrender.com/health`, должно быть `OK`.
4. `https://АДРЕС.onrender.com/admin` → войти:
   - **Филиалы** → «➕ Филиал»: название, адрес, телефон, часы, доставка;
   - в карточке филиала: загрузить QR для перевода и скопировать строку для `online.json` кассы;
   - **Бонусы и акции**: проверить проценты и суммы.
5. На моноблоке каждого филиала установить модуль кассы по [`pos_addon/INSTALL.md`](pos_addon/INSTALL.md). Через несколько секунд меню появится на сайте.
6. В карточке филиала напечатать QR на столы и QR «Заказать онлайн» для упаковки и витрины.

Стоимость: около **$7,25 в месяц** (сервер $7 + диск 1 ГБ). Свой домен (например, `bilal.kg`) подключается в Render: Settings → Custom Domains.

## Локально

```bash
ADMIN_PASSWORD=123 python -m app.main     # http://localhost:8000 и /admin
python -m unittest discover -s tests -t . # тесты
```

## Как устроен заказ

```
клиент: сайт → «Заказать»
   ↓ (касса спрашивает сайт каждые 4–5 с)
касса: 🔔 «Новый онлайн-заказ» → [📞 Позвонил, если сумма большая] → ✅ Принять
   ↓ заказ создаётся в кассе как обычный: кухня видит, чеки печатаются
касса: «Вызвать» → на сайте «Готов» / «В пути»
касса: закрыть или оплатить заказ → на сайте «Выдан», клиенту начисляются бонусы
```

Отклонить заказ можно с причиной, клиент её увидит. Потраченные бонусы при этом возвращаются.
