# Онлайн-заказы в кассе (bilal-pos)

Новые таблицы, миграции и библиотеки не нужны.
Касса сама раз в несколько секунд спрашивает сайт, нет ли новых заказов. Поэтому на моноблоке нужен только интернет, роутер настраивать не надо.

## 1. Скопировать 5 файлов

| Откуда (этот репозиторий) | Куда (bilal-pos) |
|---|---|
| `pos_addon/orders/online.py` | `orders/online.py` |
| `pos_addon/orders/online_views.py` | `orders/online_views.py` |
| `pos_addon/orders/online_urls.py` | `orders/online_urls.py` |
| `pos_addon/templates/online.html` | `templates/online.html` |
| `pos_addon/static/js/online_badge.js` | `static/js/online_badge.js` |

## 2. `config/urls.py`: добавить одну строку

```python
urlpatterns = [
    path('admin/', admin.site.urls),
    path('online/', include('orders.online_urls')),   # ← новая строка
    path('', include('orders.urls')),
] + static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

## 3. Значок с уведомлением на экранах кассы

Вставьте эту строку перед `</body>` в файлах `templates/menu.html`, `templates/orders.html`,
`templates/orders_ready.html` и `templates/edit_order.html`:

```html
<script src="/static/js/online_badge.js"></script>
```

Слева внизу появится кнопка «🌐 Онлайн». Когда приходит заказ, она краснеет и пищит каждые 5 секунд, пока заказ не примут. Нажатие на кнопку открывает вкладку онлайн-заказов.

По желанию в `templates/orders.html` в верхнее меню (рядом с «Меню», «Заказы») можно добавить ссылку:
`<a href="/online/">🌐 Онлайн</a>`

## 4. Звук без нажатия: `bilal.bat`

Chrome не даёт сайту пищать, пока по экрану ни разу не нажали. Чтобы звук работал сразу, добавьте флаг:

```bat
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --autoplay-policy=no-user-gesture-required http://127.0.0.1:8000/menu/
```

## 5. Файл `online.json` (на каждом моноблоке свой)

Откройте админку сайта → «Филиалы» → нужный филиал → «Подключение кассы». Скопируйте строку оттуда в файл `online.json` и положите его рядом с `manage.py`:

```json
{"url": "https://bilal-online.onrender.com", "token": "ключ-этого-филиала"}
```

- Ключ у каждого филиала свой: по нему сайт понимает, чьи это заказы.
- **Не загружайте `online.json` на GitHub**: добавьте строку `online.json` в `.gitignore` кассы.
- Если ключ попал в чужие руки, в админке нажмите «Выдать новый ключ».

Перезапускать кассу не нужно: файл читается сам.

## Как это работает

- **Меню.** Касса сама отправляет на сайт блюда, цены и фото. Блюдо с `is_active = False` на сайте скрывается: это и есть стоп-лист.
  - Позиции «Доставка», «С собой», «Здесь» на сайт не попадают: по ним касса определяет тип заказа.
  - Цены меняются на кассе и через пару секунд обновляются на сайте.
- **Принять.** Заказ создаётся в кассе как обычный: кухня его видит, печатаются чеки, клиенту на сайте показывается номер заказа.
  - Если в кассе есть позиция «Доставка», она добавляется в заказ с ценой доставки, а «С собой» и «Здесь» — с нулевой ценой. Так на чеке виден тип заказа.
  - В примечании к заказу: имя, телефон, адрес, комментарий, способ оплаты.
- **Статусы.** Когда кассир нажимает «Вызвать», на сайте заказ становится «Готов».
  - Закрыли или оплатили заказ на кассе — на сайте он «Выдан», и клиенту начисляются бонусы.
  - Отменили на кассе — заказ отменяется и на сайте, бонусы возвращаются клиенту.
- **Большой заказ** (сумма задаётся в админке). Кнопка «Принять» не работает, пока кассир не позвонит клиенту и не нажмёт «📞 Позвонил».
- **Перевод.** Во вкладке видно «🧾 Чек». Кассир проверяет поступление в банковском приложении и нажимает «💰 Деньги пришли»: заказ в кассе отмечается оплаченным.
- **Пауза.** Кнопка вверху вкладки временно закрывает приём онлайн-заказов, например когда завал.
- **Отчёты кассы.** Онлайн-заказы попадают в обычные отчёты. Скидка бонусами видна в примечании, а сумма заказа (`total`) уже с её учётом.
